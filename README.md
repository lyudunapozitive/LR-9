# Лабораторна робота №9. Побудова надійного програмного забезпечення: обробка виняткових ситуацій

**Виконала:** СТУДЕНТКА ГРУПИ ЕІ-24-1 МУНТЯН М.О.  
**Варіант:** 20

## Мета роботи

Опанування практичних навичок обробки виняткових ситуацій мовою Python, створення власної ієрархії класів винятків, використання конструкції `try-except-else-finally` та механізму ланцюжків винятків `raise ... from`.

## Завдання 1. Створення користувацьких класів винятків

**Модуль:** `custom_exceptions.py`

**Апаратний вузол:** Контролер шини USB 3.2.

**Реалізовані класи:**
- `USBSubsystemError` — базовий клас винятків підсистеми USB.
- `VBUSOverCurrentError` — перевищення допустимого струму порту.
- `MaxPacketSizeInvalidError` — некоректний розмір пакета.

## Завдання 2. Валідація конфігурації контролера USB 3.2

**Модуль:** `device_validator.py`

**Контрольовані параметри:**
- Струм порту USB — не більше 900 мА.
- Допустимий розмір пакета — 512 або 1024 байти.
- Перевірка кількості кінцевих точок.

**Реалізовані операції:**
- Перевірка наявності обов'язкових параметрів конфігурації.
- Перевірка типів вхідних даних.
- Генерація користувацьких винятків за допомогою `raise`.
- Використання механізму `raise ... from` для збереження першопричини помилки.
- Перехоплення винятків конструкцією `try-except`.
- Виконання блоків `else` та `finally`.
- Формування діагностичних повідомлень.

## Завдання 3. Тестування відмовостійкості

**Модуль:** `device_validator.py`

Реалізовано тестовий стенд для перевірки коректних і некоректних конфігурацій контролера USB 3.2.

**Результати тестування:**
- Усього тестових наборів: 7.
- Успішних конфігурацій: 2.
- Локалізованих та оброблених збоїв: 5.
- Коефіцієнт програмного відновлення: 100%.
- Час виконання: 16,565 мс.

Усі передбачені тестові помилки були успішно перехоплені програмою.
